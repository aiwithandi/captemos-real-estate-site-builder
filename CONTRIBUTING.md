# Contributing

Thank you for helping improve the viewer starter.

1. Fork the repository and create a focused branch.
2. Keep all credentials in an ignored `.env.local` file.
3. Preserve the demo fallback and server-only credential boundary.
4. Run `npm run check` and `npm run build`.
5. Describe the visible change and include screenshots when the interface changes.

Please keep example property copy, images, and branding original. Do not submit customer data or copied commercial listing content.
